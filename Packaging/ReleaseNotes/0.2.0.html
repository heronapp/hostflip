What's New

  • Remote Profiles. Point a profile at an HTTPS URL and hostflip keeps it fresh — hourly, every 6 or 24 hours, or on demand, with a catch-up refresh at launch. The editor always shows the source and how recently it refreshed, and a profile can be converted between local and remote at any time.
  • Hosts Doctor. The new hostflip doctor command traces a hostname through five layers — from your profiles down to what macOS actually resolves — and pinpoints where an entry gets lost.
  • Refresh from the command line. hostflip refresh re-fetches remote profiles from scripts and reports per-profile results, with --json for automation; list and cat now include remote metadata such as the last successful refresh.
  • A cleaner editor header. Native controls, one calm metadata line, and an always-visible freshness readout for remote profiles.
